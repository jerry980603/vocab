# 英文單字練習

一個只給你自己用的背單字網頁。**完全離線運作**，不需要帳號、不需要伺服器、不用付任何費用。
所有學習進度都存在你自己的手機瀏覽器裡。

目前字庫收錄 **440 個單字 + 52 個片語**，共 709 個字義、1062 個例句。

每個單字都對照過大考中心《高中英文參考詞彙表（111 學年度起適用）》：
**438 個字（99.5%）在官方詞彙表內，詞性依官方標註**，App 裡會直接顯示分級標籤
（<span>2級</span> 綠色、<span>3～4級</span> 藍色、<span>5～6級</span> 橘色、<span>表外</span> 紅色）。
唯二不在官方表內的是 `eventually` 與 `migrate`，已標成「表外」。

## 一、先在電腦上試玩看看

在這個資料夾裡，用滑鼠**左鍵連點兩下 `index.html`**，它就會用瀏覽器打開。
（電腦上是這樣開沒問題的，手機才需要下面第二步的架站。）

### 七個頁面在做什麼

| 底下的按鈕 | 做什麼 |
|---|---|
| **✏️ 練習** | 主畫面。最上面是**今天的進度**（新字＋到期複習），錯題獨立一段、可以分批清 |
| **📅 課表** | 把字庫依分級由淺到深切成 Day 1、Day 2…，一鍵把一整天的字加入清單 |
| **📊 紀錄** | 每天練了幾個字、幾題、多少時間；**平均一天幾個單字（含複習與錯題）、還要幾天背完** |
| **🔍 查單字** | 可搜尋**官方詞彙表全部 6114 個字**；已編好例句的能直接加入練習 |
| **📚 我的字** | 看你加了哪些字、熟練度、什麼時候要複習 |
| **🃏 錯題本** | 答錯的字自動跑來這裡，用單字卡複習 |
| **⚙️ 設定** | 備份進度、把「待補清單」複製給 Claude 補字庫 |

### 每天不用自己安排

每天第一次打開 App，它會**照課表順序自動補上當天的新字**（預設開啟，
要關掉的話到「課表 → 每天自動載入新字」切成「我自己按」）。
練習頁最上面的「今天的功課」會把**新字＋到期複習＋錯題**排成一輪，
按下去就開始，不必自己去課表挑今天該吃哪一組。

沒練的日子**不會累積**：隔天只補當天的額度，停幾天再回來也不會被淹沒。

### 目標範圍：預設只拚 1～5 級

課表的「目標範圍」預設是**官方 1～5 級的 5091 個字**。第 6 級那 1023 個字是整張表
最冷僻的一批，時間有限的話，把 1～5 級做熟比全包划算。
倒數、完成日推算、課表排序都只算這個範圍，第 6 級的字會被排到課表最後面
（還是查得到、也可以自己加）。要全包就切成「全部 6 級」。

### 時數與字數怎麼算的

- **時間**：只有停在「練習」或「錯題本」頁、而且最近 90 秒內有動作
  （打字、點畫面）才會累加，每 5 秒記一次。把 App 開著去做別的事不算。
- **練到的字義**：一天之內練到的**不重複**字義，
  **新字、到期複習、錯題全都算在裡面**。
  同一個字義同一天重複考到只算一次（答錯後十分鐘重考，題數加兩題、字義只算一個）。
- **幾天背完**：只用「新學的字義」的速度推算。複習與錯題再多也不會讓沒學過的字變少，
  它們吃掉的是你每天的時間，不是進度。
- **新學的字義**：那天新加進練習清單的數量，不管是自動載入還是自己加的。

### 練習時的三個按鈕

- **送出** — 對答案
- **提示** — 單字最多只給**前兩個字母**；片語則給**每個字的開頭字母**
  （例如 `looking forward to` → `l______ f______ t_`）。用了提示答對，熟練度不會升級
- **不會** — 直接放棄看答案。等同答錯：熟練度歸零並放進錯題本

**一般練習不會混入錯題。** 錯題有自己獨立的一輪，避免你在同一輪反覆撞同一個不會的字。

### 第一次使用的順序

1. 先點 **🔍 查單字**
2. 打幾個你想背的字（例如 `abandon`）
3. 點進去，會看到這個字**每一個意思**各自一列，按 **＋加入** 把你想背的加進來
4. 回到 **✏️ 練習**，就會開始考你了

### 練習時可以做的事

- **拼不出來** → 按「提示」，第一次告訴你共幾個字母，再按一次多給一個字母
  （用了提示答對，熟練度不會升級，這是故意的）
- **句子裡有不認識的字** → 直接**點那個字**，會跳出它的意思，可以當場加入練習清單
  字庫裡沒有的話，可以按「加入待查清單」，之後叫 Claude 補
- **覺得例句怪怪的** → 按最下面「這句怪怪的」，之後到設定一次複製給 Claude 修

### 它怎麼安排複習（間隔重複）

每個字義都有一個「熟練度」0～7，對應這條間隔階梯：

| 熟練度 | 下次考你的時間 |
|---|---|
| 1 | 10 分鐘後（確保同一次讀書時間內一定會再遇到一次） |
| 2 | 1 天後 |
| 3 | 4 天後 |
| 4 | 14 天後 |
| 5 | 30 天後 |
| 6 | 60 天後 |
| 7 | 120 天後 |

**但你不會一格一格走。** 跳格規則是：

- **第一次看到就答對（沒用提示）→ 直接跳到「30 天後」那一格。**
  Cepeda 等人 2008 年的研究指出，最佳複習間隔約是「測驗延遲的 10～20%」；
  距離學測還有一百多天，20% 就是二十幾天。原本設計的 4 天遠低於最佳值，
  那不是保險，是把時間花在低效區。
- **之後每答對一次跳兩格。**
  FSRS（Anki 現在的排程演算法，用上億筆真實複習紀錄訓練）的資料顯示，
  一次成功複習會讓記憶的穩定度變成**大約 3 倍**，而這條階梯只有 2 倍。
  一格一格走，排程會越來越落後於你實際記得的程度，等於浪費複習次數。
  改成跳兩格之後，模擬的總題數少 22%，而考試當天的預期保留率只從
  98.6% 掉到 97.1%——**考前十天的總複習會把差距補回來**，那才是真正的保護網。
- **答錯或按「不會」→ 退兩格**（不是歸零），10 分鐘後重考，同時進錯題本。
  全歸零會讓一個已經複習到 60 天間隔的字重走整條階梯，每日複習量因此暴增。
  錯題本裡的字**再答對一次就畢業**。

每次都在你快要忘記的時候考你。這是間隔重複的核心：
不是練越多次越好，而是**在遺忘邊緣重新提取**最有效。

**錯題本的卡片是純翻閱用的**，翻卡不會改動任何熟練度。
要讓一個字離開錯題本，用「重練這組」把它答對一次。

**用了字母提示答對只升一格**（不走上面的大跳）。有提示的回想比較容易，
給大跳會讓系統高估你的熟練度、把複習排得太遠；但完全不升也不行——
熟練度卡在 0 的字，下次到期時間會變成「現在」，於是它每一輪都再出現、
永遠停在 0 級，還一直算在今天的進度裡（2026/09 修掉的 bug）。
按 Shift 翻中文**不算**提示，只有按「提示」給字母才算。

### 不浪費時間在你早就會的字（重要）

每天上七十個新字時，如果簡單的字跟難的字排一樣多次複習，大半時間都是白費的。
三個機制會自動把它們濾掉：

- **快篩**（練習頁下方）：只問你「會不會」，會的直接跳過、永遠不排進練習。
  這是最有效的一招——它讓那個字**連第一次都不用考**。
  模擬顯示每天的時間有很大一塊是被「第一次見面就答錯」的字吃掉的。
- **第一次看到就答對（沒用提示）→ 直接跳到 30 天後**，不用陪它從頭走完整的階梯
  （用了字母提示則只升一格，見上面）
- **練習畫面下方的「這個我早就會了」** → 熟練度直接推到接近滿級

所以清單裡放一堆你已經會的字並不會拖垮你——它們第一輪就會被篩掉。

「每天最少學幾個新字」是**下限不是上限**。練完當天的量還想繼續，
可以隨機加練，或直接到課表把下一個 Day 也吃掉。

## 二、放到手機上（免費，約 10 分鐘）

用 GitHub 免費架站，架好之後手機開一次，加到主畫面，之後**沒網路也能用**。
全程用網頁點一點就好，不用打指令。

### 步驟

1. **註冊 GitHub 帳號**
   到 <https://github.com/signup>，用 email 註冊一個免費帳號。

2. **建立一個 repository（放檔案的地方）**
   - 登入後點右上角 **＋** → **New repository**
   - Repository name 填 `vocab`（隨便取，英文小寫）
   - **Public** 要選著**（Private 的話免費版沒辦法架站）**
   - 按 **Create repository**

3. **把檔案上傳上去**
   - 在新頁面上找到 **uploading an existing file** 這行連結，點它
   - 把這個資料夾裡的 **`index.html`、`app.js`、`sw.js`、`manifest.json`、`icon.svg`** 一起拖曳進去
   - **`data` 整個資料夾**也一起拖進去（可以直接拖資料夾）
   - 拉到最下面按綠色的 **Commit changes**

4. **打開 Pages 功能**
   - 點上方的 **Settings** → 左邊選單找到 **Pages**
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**，資料夾選 **/ (root)**，按 **Save**
   - 等 1～2 分鐘，重新整理這頁，上面會出現你的網址：
     `https://你的帳號名.github.io/vocab/`

5. **手機加到主畫面**
   - 用手機瀏覽器打開那個網址
   - **iPhone（Safari）**：按下面正中間的分享鈕 → 往下滑找「加入主畫面」
   - **Android（Chrome）**：按右上角三個點 → 「加到主畫面」
   - 之後從主畫面點開，就跟一般 App 一樣，**飛航模式也能用**

> ⚠️ 進度存在手機瀏覽器裡。**換手機、或清除瀏覽器資料之前**，
> 記得先到「設定 → 匯出」，把那一大串文字複製起來存到記事本。

## 三、要加更多單字的時候

在這個資料夾裡打開 Claude Code，直接跟它說就好，例如：

```
幫我加 100 個學測常考的形容詞進單字庫
```

```
幫我把這些字加進去：intrigue、conform、plausible
```

如果是從 App 裡累積的，更省事：
到 **⚙️ 設定 → 待查單字 → 複製指令**，貼給 Claude Code 就好，它會自己知道要做什麼。

改完之後，重複上面**第 3 步**把 `data` 資料夾重新上傳一次，手機重新整理就會更新。

## 四、檔案在哪些地方

```
index.html      畫面（版面、配色）
app.js          程式（練習邏輯、間隔重複、錯題本）
sw.js           離線快取，讓你沒網路也能用
manifest.json   讓它能「加到主畫面」變成 App 的樣子
icon.svg        App 圖示
data/
  bank.js       單字庫的格式定義（不用改）
  w1.js ~ w5.js 單字（A→Z 分五個檔）
  p1.js         片語
CLAUDE.md       給 Claude Code 看的說明，它會照這個格式加字
```
